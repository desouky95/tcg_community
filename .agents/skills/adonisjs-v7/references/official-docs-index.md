# Official AdonisJS v7 Markdown sources

This is a **link index** to the current official Markdown pages, not a copy of their content. The AdonisJS documentation publishes this format and also offers its complete [llms.txt](https://docs.adonisjs.com/llms.txt) index.

The downloader `scripts/sync-official-docs.mjs` can fetch any/all of the pages by ID into `references/official/` for offline reference. Check upstream licensing before redistributing fetched copies.
