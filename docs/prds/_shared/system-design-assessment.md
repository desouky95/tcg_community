# Decisions required before implementation

- Define AdonisJS-to-Medusa identity linking, provisioning, sessions and recovery.
- Select and design fee payment, verification, reconciliation and refund integration.
- Approve middleman inspection scope, custody chain, losses, returns, cancellation, refund and dispute policies.
- Define operational eligibility, service area, fee configuration permissions and reporting response procedures.
- Audit existing implementations, contracts and migrations before marking any scenario implemented; test fresh database setup for each backend.

These open decisions do not change the agreed boundaries or permit marketplace listings.
