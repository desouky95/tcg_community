# TCG Nexus brand guidelines

## Positioning

TCG Nexus is the Egypt-first home for collectors who want to organise, find,
trade, and eventually buy cards with confidence. It should feel like a real
collector's desk: considered, slightly tactile, and rich with useful detail.

## Voice

- Clear and direct: “Add to collection”, “Find a match”, “Review seller”.
- Warm, informed, and community-minded; never salesy or overly corporate.
- Use collector vocabulary when it helps, then explain it in plain language.
- English is the source language. Arabic translations should be natural and
  preserve the same calm, confident tone.

## Visual direction

The interface uses a dark graphite base inspired by card binders and desk mats.
Orange marks the active tab, action, or trade opportunity. Cobalt is reserved
for discovery and links. Paper-white type and muted slate metadata keep dense
collection screens readable.

| Token | Hex | Use |
| --- | --- | --- |
| Graphite 950 | `#0B0F14` | App background |
| Graphite 900 | `#121820` | Navigation and deep surfaces |
| Graphite 800 | `#1A232D` | Cards and panels |
| Paper | `#F4F0E8` | Primary text |
| Slate | `#9BA7B5` | Metadata and helper text |
| Ember | `#F26B3A` | Primary action, active tab, trade state |
| Cobalt | `#4E7BFF` | Links, discovery, selected data |
| Mint | `#63C6A2` | Confirmed and complete states |

## Typography

- Display: `Space Grotesk`, 600–700, for product names and major headings.
- Body: `DM Sans`, 400–600, for UI copy and descriptions.
- Utility: `IBM Plex Mono`, 500, for card numbers, prices, IDs, and counts.

## Logo

The mark is a clipped card corner enclosing a four-point “N” path. Keep the
mark at least one mark-height away from other graphics. Use the full lockup in
navigation and the mark alone for app icons, avatars, and compact mobile UI.

## Interaction principles

- Every screen has one obvious primary action.
- Tabs and metadata should feel like binder index labels, not decoration.
- Use motion to clarify navigation and state changes; respect reduced motion.
- Never rely on color alone for ownership, availability, or moderation state.
