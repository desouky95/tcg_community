# Technical privacy audit: third-party services and processors

“Configured in source” does not prove production use. Processor/controller roles and contract status require legal and account-level review. No credentials reproduced.

| Service | Source evidence / status | Data likely involved | Risk / missing evidence |
|---|---|---|---|
| Google OAuth | Better Auth provider configuration: `apps/public-web/src/lib/auth/better-auth.server.ts`; credentials named in env/docs, not shown. Integration implemented/configurable. | OAuth account identifiers and claims returned by configured scopes. | Verify scopes, production enablement, Google entity/region, retention, DPA/transfer terms. |
| Facebook OAuth | Same Better Auth and Adonis identity bridge; implemented/configurable. | Provider identifier and profile claims; potentially email. | Verify scopes and actual usage; email match explicitly should not be treated as account linking (`apps/api/docs/facebook-login.md`). Obtain vendor terms/transfer details. |
| DigitalOcean Spaces / S3-compatible | Medusa S3 provider in `apps/backend/medusa-config.ts`; Strapi `aws-s3` upload provider in `apps/cms/config/plugins.ts`. Configured. | Product/CMS media; potentially personal information in user-uploaded assets and metadata. | Verify account, bucket ACL/public access, region, CDN, backups, deletion and vendor contract/subprocessors. |
| Database providers | Medusa consumes `BACKEND_DATABASE_URL`; API uses configured database (`apps/api/config/database.ts`); Strapi supports Postgres/MySQL/SQLite and defaults SQLite (`apps/cms/config/database.ts`). | Accounts, commerce, content and operational records. | Actual engine, host, region, encryption, backups, retention, access and managed provider not discoverable from source. |
| Redis/event/locking | Optional Medusa Redis event bus and locking provider when `BACKEND_EVENTS_REDIS_URL` exists: `apps/backend/medusa-config.ts`. Conditional integration, enabled only by deployment env. | Event payloads/job metadata may contain identifiers or order/customer references. | Confirm production setting, payload minimization, queue retention and provider region. |
| InstaPay / bank | Custom offline payment provider and payment instructions route: `apps/backend/src/modules/offline-payment/service.ts`, `apps/backend/src/api/store/payment-instructions/route.ts`. Implemented app flow; exact bank/provider unknown. | Payment transaction/account details processed through external banking app/provider. | Confirm legal entity, data fields, reconciliation workflow, receipts and retention. |
| Shipping/fulfillment | Medusa fulfillment options are used by checkout, but a named courier implementation was not established in reviewed source. | Recipient name, phone, delivery address and order details necessarily used for fulfillment. | Identify actual courier(s), integration/data sharing, locations, retention and contracts. |
| External card catalog | Custom catalog modules use configured base URL/API key: `apps/backend/medusa-config.ts`; Adonis scraper references external LastSticker source. | Catalog requests and operational credentials; no user data flow evidenced by configuration alone. | Confirm endpoints, logs and whether identifiers ever enter requests. |
| Email delivery | Adonis mail config exists (`apps/api/config/mail.ts`) and a prior project implementation may configure a provider by env; no active email verification path established in route review. | Potential account notifications/addresses if mail sending is enabled. | Confirm provider and production use. Resend is not asserted as active absent deployed provider evidence. |
| Analytics/advertising | No active analytics or advertising integration established in reviewed app code. | Unknown. | Search deployment scripts, tag manager/CDN injection and vendor dashboards before concluding absent. |
| Hosting/observability | No definitive production host or logging processor established by source review. | Application traffic, IPs, request metadata and logs likely handled by hosting. | Obtain deployment inventory, region, log/metrics vendors, retention, incident and subprocessor lists. |

No customer records or secret values were inspected or included.
